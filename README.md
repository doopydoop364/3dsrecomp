# 3DS-Decrypt / 3dsrecomp

This repository started from aszuraz's 3DS-Decrypt (CIA/3DS decryption scripts, now in `3dsrecomp/extract/`, documented in [`3dsrecomp/extract/README.md`](3dsrecomp/extract/README.md)) and
grew into **3dsrecomp**: native Linux ports of 3DS games by static recompilation. See [`3dsrecomp/README.md`](3dsrecomp/README.md).

Game dumps, keys and anything produced from them are never committed; use your own dumps only.
